# Vuga Ndakumva website release history

## First push — 21 November 2026

Commit `99cd730` (`Update Vuga site design and content`) brought the redesigned website to the repository and the first live deployment. It included the About Us page and team portraits, the shared brand and footer logo, homepage and awareness imagery, updates to mental-health, alcohol and drugs, and GBV learning content, and navigation and accessibility refinements.

## Second push — 21 November 2026

This release builds on the first push and includes:

- Search metadata, canonical URLs, social sharing information, sitemap, robots instructions, and route-specific HTML for public pages. Pages still in development are excluded from indexing.
- A more compact shared footer using the header green and white text, with links to the initiative's six social profiles.
- Phone icons next to the emergency numbers in the header.
- Clearer illustration captions that retain the distinction between fictional teaching scenes and real people.
- Responsive footer, learning-content and SEO checks, plus a production build.

The old database is separate from the static site and its removal is tracked separately from the website release.
